# LIBROS FORESVI - Platform Overview

## Vision
A premium educational platform that solves "Infotoxication" by curating high-quality content and leveraging community validation. The goal is to separate "the wheat from the chaff".

## 🚀 Current Status (MVP Phase 1 Complete)
The visual foundation and core value proposition are built.

### ✅ Implemented Features
1.  **Brand Identity**: Adapted to **FORESVI** manual (Blue `#202189`, Inter Tight font, Clean Light Design).
2.  **Landing Page Structure**:
    *   **Hero**: Value prop ("Aprende sin Infotoxicación").
    *   **Methodology**: Visual explanation of Curation -> Personalization -> Validation.
    *   **Featured Courses**: Examples of "Validated Content" (Solar, Safety, etc.) with instructor authority.
    *   **Pricing**: 3 Tiers (Viewer, Particular VIP, Business VIP) defined in strategy.
    *   **Call to Action**: Recruitment for new instructors/experts.

### 🎨 Design System
*   **Theme**: Clean Light (White backgrounds, slate text).
*   **Typography**: `Inter Tight` (Corporate font).
*   **Interactions**: Hover effects, smooth scrolling, responsive cards.

---

## 📅 Roadmap: Next Steps (Phase 2)

To transform this from a Landing Page to a **Functional Platform**, we need to tackle these areas:

### 1. Course Experience (The "Product") 📺
*   **Course Detail Page**: Create the template for viewing a specific course.
    *   Video Player.
    *   Curriculum/List of chapters.
    *   Attachment downloads (PDFs for VIPs).
*   **Validation UI**: Implement the actual buttons for users to "Validate" content (Thumbs up/Verification badge).

### 2. Authentication & User Roles 🔐
*   **Login/Signup Screens**: Beautiful entry points for users.
*   **Access Control**: 
    *   *Free Users* -> See ads or limited content.
    *   *VIPs* -> Full access, no ads.

### 3. Content Management (The "Engine") ⚙️
*   **Data Structure**: Define the JSON/Database structure for Courses, Instructors, and Lessons.
*   **Dynamic Loading**: Stop using "dummy data" and load courses from a central file (or future database).

### 4. Interactive "Search & Filter" 🔍
*   Allow users to filter by "Solar", "Electricity", "Safety" to find that specific "needle in the haystack".
